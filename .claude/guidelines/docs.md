# Docs

`README.md` covers what the project is, the tech stack, the project structure, how to run it locally, and the AI
tooling available for manual invocation, both skills and any MCP server configured for this project
specifically. Keep it true to the current state of the repo in the same task that changes it, in two directions:
update it when a change makes something it already says inaccurate (a command, a setup step, a script's
behavior, a feature it describes), and add to it when a change introduces something it should cover but doesn't
yet (a new human-invocable skill, a new project-specific MCP server, a new setup step, a change to the tech
stack or the project structure). Silence is only correct when nothing in that list actually moved.
